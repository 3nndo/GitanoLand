# Smokeleaf Industries: guía rápida (sacada del código del mod 0.7.1)

Las recetas exactas no las tengo: míralas en el Smokeleaf Guide del juego o en REI/JEI.

## Cadena de producción
1. **Cultivo:** semillas en la Grow Pot, con LED Light / Reflector y fertilizantes (cada cepa pide su N-P-K). El Plant Analyzer analiza plantas.
2. **Cosecha:** sale el bud fresco.
3. **Secado:** Drying Rack (rack) o Dryer (máquina) -> bud seco.
4. **Molienda:** Grinder (máquina) o Manual Grinder (item) -> weed.
5. **Productos:** Joint (2 papeles + weed), Blunt (6 papeles + weed), Bong (weed en la otra mano), Dab Rig (extracto en la otra mano), gummies y gummy worms (Gummy Machine: molde + catalizador + aceite), comida (herb cake, hash brownie, weed cookie, butter/infused butter), Extractor (weed -> extracto), Liquifier (-> fluido), Generator (quema material y da energía).
6. **Logística:** Item/Fluid/Energy Pipe con Pipe Wrench.

## Genética
DNA Strand guarda genética. Sequencer (ADN + extracto base + reactivos), Synthesizer (ADN -> resultado), Mutator (ítems + fluido), Strain Modifier (ajusta parámetros), Mixer (mezcla extractos: THC/CBD = media ponderada), Strain Book (guardar y copiar cepas).

## Efectos
- Duración base = 10 s + 0,5 s x CBD (CBD 0-100), por el multiplicador del producto.
- Efectos extra por THC: >10 -> 1, >15 -> 2, >25 -> 3 (deterministas).
- Siempre se aplica Stoned, que activa el shader. Tier visual por THC (umbrales): Mellow Buzz 4, Couch Lock 9, Baked Haze 13, Ganja Goggles 15, Dank Wobble 17, Hotbox Vision 19, Terpene Trails 21, Sticky Fingers Static 23, Blazed Bloom 25, Kush Kaleidoscope 28, Astral Vortex 31, Cosmic Couchlock 35.
- CBD alto (27-30) acorta el Stoned hasta un 60 %.
- Repetir la misma cepa 3 veces seguidas "confirma" el efecto.
